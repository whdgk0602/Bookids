# Bookids

**아이가 말하면, 그 말이 그림책이 됩니다.**

Bookids는 만 4~5세 유아를 위한 AI 그림책 만들기 서비스입니다. 아이가 그림을 그리고 그림 이야기를 들려주면, AI 캐릭터 "토리"가 아이의 말을 완성된 문장으로 되받아 주고 다음 이야기를 묻습니다. 아이의 대답 하나하나가 아이 그림체를 살린 삽화와 함께 한 페이지가 되고, 대화가 끝나면 한 권의 그림책이 완성됩니다.

기존 AI 동화는 아이가 듣기만 합니다. Bookids는 아이가 **말하는 사람**이 되도록 설계했습니다.

> 현재는 **프로토타입** 단계입니다. 인터뷰·시연용이며, 실제 아이의 목소리나 그림은 넣지 않습니다.

## 어떻게 동작하나요

```
그림 그리기·사진 찍기 → 토리가 그림을 보고 첫 질문
        ↓
아이가 마이크를 누르고 말하기 → 음성인식
        ↓
토리의 되받기("숲에서 곰을 만났구나!") + 다음 질문 → 삽화 생성 (페이지 1장)
        ↓  (반복)
결말 → 그림책 완성 → 보호자 공유 링크
```

### 핵심 설계

- **되받기 (확장해 되돌려 주기)**: 아이가 "곰"이라고만 말해도 토리는 "숲에서 곰을 만났구나!"처럼 완성된 문장으로 돌려준다. 유아 언어 자극 기법을 대화에 넣었다.
- **비계 (질문 난이도 조절)**: 아이가 "몰라"라고 하거나 대답하지 않으면 질문을 점점 쉽게 바꾼다. 열린 질문 → 좁힌 질문 → 그림 카드 선택지 순서다. 길게 대답하면 다시 열어 준다. 난이도 판단은 AI가 아니라 코드 규칙이 맡아서 매번 같은 기준이 적용된다.
- **이야기 흐름**: 사건 → 감정 → 원인을 돌아가며 묻고, 페이지가 쌓이면 결말을 묻는다. 아이가 "끝"이라고 말하면 바로 마무리한다.
- **아이 그림체 유지**: 삽화는 아이가 그린 그림을 참조해서 그리고, 등장인물 생김새를 페이지마다 같게 유지한다.
- **안전**: 아이에게 나가는 모든 문장은 안전 필터를 거친다.
- **기록**: 아이 발화 어절 수, 무응답 수, 응답 시간을 세션마다 남긴다. 앞으로 언어발달 지표와 관찰기록 초안으로 확장할 데이터다.

## 사용 기술

| 영역 | 사용 |
|---|---|
| 앱 | Next.js 16 (App Router), React 19, Tailwind CSS v4, TypeScript |
| 음성인식 | Groq Whisper `large-v3` |
| 대화 (되받기·질문) | Groq `gpt-oss-120b`, 실패 시 Gemini로 자동 전환 |
| 그림 인식 | Google Gemini `3.5-flash` |
| 삽화 | Cloudflare Workers AI FLUX.2 klein 4B |
| 캐릭터 음성 | 브라우저 내장 음성 합성 |
| 그림책 저장 | 로컬: `data/books` 폴더 / 배포: Vercel Blob (비공개) |
| 배포 | Vercel |

프로토타입은 모두 무료 등급으로 동작합니다. 무료 등급은 입력이 학습에 쓰일 수 있어서, 실제 아이 테스트 전에는 유료 키로 바꾸고 보호자 동의를 받아야 합니다.

## 화면

| 경로 | 내용 |
|---|---|
| `/` | 홈 |
| `/story` | 이야기 만들기 (그림 → 대화·삽화 반복 → 완성 그림책) |
| `/book/[id]` | 저장된 그림책 (보호자 공유용 읽기 전용 링크) |
| `/check` | 기기 점검 (보안 연결, 마이크 녹음) |

| `/dev/sim` | 대화 엔진 시뮬레이터: 글자로 대답하며 질문 품질 확인 (팀 내부용) |

## 실행

```bash
npm install
cp .env.example .env.local   # 키를 채운다. 키 없이 보려면 AI_MODE=mock 그대로
npm test                     # 단위 테스트 (비계 규칙, 안전 필터, 저장소 경로 검사)
npm run dev                  # http://localhost:3000
```

- PC의 `localhost`에서는 HTTP로도 마이크가 동작한다.
- 태블릿·휴대폰에서는 HTTPS가 필요하다. Vercel 배포 주소를 쓰거나, `npm run tunnel`로 임시 HTTPS 주소를 만든다. 터널은 주소를 아는 누구나 들어올 수 있으니 테스트가 끝나면 바로 끈다.

### Vercel 배포

1. Settings → Environment Variables에 `.env.example`의 항목을 넣는다 (`AI_MODE=live` 필수).
2. Storage에서 **Private** Blob 저장소를 만들어 프로젝트에 연결한다 (`BLOB_READ_WRITE_TOKEN` 자동 추가). 연결하지 않으면 그림책 저장·공유 링크가 동작하지 않는다.

- [x] 그림 입력 (그리기 캔버스, 사진 촬영·앨범, 샘플 그림)
- [x] 음성 입력과 음성인식
- [x] 대화 엔진 (그림 인식, 되받기·질문 생성, 비계 규칙, 캐릭터 음성, 안전 필터)
- [x] 아이 그림을 참조한 삽화 생성
- [x] 그림책 완성·저장, 보호자 공유 링크, 세션 기록
- [x] 시연 준비 (공급자 자동 전환, 응답 시간 측정, 기록 화면)
- [ ] 실사용 검증: 실제 음성으로 한 권 완성, 태블릿·휴대폰 테스트, 처음 보는 사용자 사용성 테스트

다음 단계(MVP)에서는 계정·보호자 동의, 유아 발화 보정과 되묻기 확인, 언어발달 분석, 교사 대시보드를 다룬다.
