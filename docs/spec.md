# Bookids 기능명세

> 아이의 그림과 말을 입력으로 받아, AI가 되물으며 이야기를 이어 가고, 대답을 삽화로 그려 한 권의 그림책을 완성한다. 그 과정의 발화는 언어발달 지표와 관찰기록 초안으로 교사·보호자에게 제공된다.

## 1. 기준

### 적용 단계

날짜가 아니라 **목적**으로 구분한다. 앞 단계가 끝나야 다음 단계로 간다.

| 단계 | 목적 | 끝났다고 보는 기준 |
|---|---|---|
| **프로토타입** | 핵심 체험 한 바퀴를 보여 준다 (인터뷰·시연용) | 처음 보는 아이가 안내 없이 그림책 1권을 완성한다 |
| **MVP** | 실제 유치원에 투입할 수 있다 | 동의·계정·안전·기본 분석이 갖춰져 파일럿 기관에 배포할 수 있다 |
| **파일럿** | 효과와 교사·보호자 가치를 검증한다 | 사용 반/미사용 반 비교 데이터와 교사·보호자 피드백이 모인다 |
| **고도화** | 파일럿 결과를 반영해 품질을 높인다 | 파일럿에서 나온 주요 문제가 해결된다 |
| **정식 출시** | 유료로 판매한다 | 기관·가정이 스스로 가입하고 결제할 수 있다 |
| **확장** | 부가 매출·채널을 늘린다 | — |

### 우선순위

| 등급 | 의미 |
|---|---|
| **P0** | 해당 단계에서 없으면 그 단계의 목적을 달성할 수 없다 |
| **P1** | 해당 단계에서 있어야 하지만, 부족하면 다음 단계로 넘길 수 있다 |
| **P2** | 여유가 있을 때 |

### 사용자

아이 · 교사 · 보호자 · 기관 관리자 · 운영자(Bookids 내부)

### 완료 기준 표기

완료 기준의 숫자(예: "2회", "5어절")는 **초기 가정값**이다. 프로토타입·파일럿에서 조정하며, 바뀌면 이 문서를 갱신한다.

## 4. 프로토타입 상세 범위

**넣는 것:** 그리기·촬영 → 그림 인식 → 누르고 말하기 → 되받기·질문(3단계 비계, 선택지 카드) → 삽화(같은 원본 그림 참조) → 마무리 → 그림책 보기 → 세션 로그 내보내기

**빼는 것:** 로그인·계정·동의, 분석·지표, 대시보드, 공유, 결제, 음성 보관

**프로토타입 전용 규칙**

- 실제 아이와 테스트하기 전에 AI API를 **학습에 사용하지 않는 유료 등급**으로 바꾼다.
- AI 호출부는 공급자 교체가 가능하게 분리하고, 키가 없을 때 동작하는 mock 모드를 둔다.
