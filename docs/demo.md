# Bookids 프로토타입 시연 안내

교사·학부모 인터뷰와 유치원 시연에서 쓰는 진행 순서와 준비물. 시연 전에 이 문서 순서대로 점검한다.

## 1. 시연 전 점검 (전날)

| 확인 | 방법 |
|---|---|
| 개발 서버가 뜨는가 | `npm run dev` → `http://localhost:3000` |
| AI가 실제로 동작하는가 | `/dev/sim`에서 대답 2~3개 입력 → 턴마다 `groq`가 보이고 1~2초 안에 응답 |
| 삽화가 그려지는가 | `/story`에서 샘플 그림으로 한 페이지 만들기 → 이모지가 아니라 그림이 나오면 정상 |
| 오늘 남은 무료 사용량 | 삽화는 하루 약 90장(그림책 약 15권). `/dev/books`의 뉴런 합계로 확인 |
| 태블릿·휴대폰에서 열리는가 | `npm run tunnel` → 출력된 `https://….trycloudflare.com` 주소를 기기에서 열고 `/check`에서 녹음 확인 |
| 미리 만든 그림책 | `/dev/books`에 샘플 그림책 2~3권이 있는지 (현장 인터넷이 안 될 때 대신 보여 줌) |

## 2. 진행 순서 (약 10분)

1. **문제 소개 (1분)**: "기존 AI 동화는 아이가 듣기만 합니다. 이 서비스는 아이가 말하면 그 말이 그림책이 됩니다."
2. **그림 고르기 (1분)**: `/story` → "샘플 그림"(토끼·고양이·공룡) 또는 "그리기". 토리가 "마이크를 꾹 누른 채로 그림 이야기를 들려줘"라고 안내한다.
3. **이야기 만들기 (5분)**: 참석자(또는 아이 역할)가 마이크를 누르고 말한다.
   - **되받기 보여 주기**: 짧게 "곰"이라고만 말해 보면 토리가 "숲에서 곰을 만났구나!"처럼 완성된 문장으로 돌려준다. → 언어 자극 기법(확장해 되돌려 주기) 설명
   - **비계 보여 주기**: "몰라"를 두 번 말하면 질문이 쉬워지고, 더 이어지면 그림 카드 선택지가 나온다. 오른쪽 위 표시(예: "감정 · 선택지")로 지금 단계를 보여 준다.
   - **삽화**: 대답할 때마다 아이 그림체를 살린 삽화가 뒤에서 그려진다 (약 4초, 기다리지 않음).
4. **완성 그림책 (2분)**: "그림책 보기" → 표지·페이지 넘기기. 끝 페이지의 **어른용 → 공유 링크**로 보호자가 보는 화면을 보여 준다.
5. **기록 (1분)**: `/dev/books`에서 이 세션의 아이 발화 어절 수, 무응답 수, 응답 시간을 보여 준다. → 향후 언어발달 지표·관찰기록으로 이어질 데이터라고 설명

## 3. 현장에서 문제가 생기면

| 상황 | 대처 |
|---|---|
| 토리 대답이 느리다 (5초 이상) | 무료 AI가 붐비는 시간. 그대로 진행하거나, 미리 만든 그림책으로 넘어간다 |
| 삽화가 이모지로만 나온다 | 하루 무료 사용량을 넘었거나 검열에 걸린 것. 이야기는 계속되므로 그대로 진행한다 |
| 음성인식이 엉뚱하게 받아 적는다 | "지금은 일반 음성인식이라 그렇고, 유아 발화 보정과 되묻기 확인이 정식 기능"이라고 설명 (명세 INP-05, DLG-06) |
| 인터넷이 안 된다 | `.env.local`의 `AI_MODE=mock`으로 바꾸고 서버를 다시 켜면, 정해진 토끼 시나리오로 화면 흐름 전체를 보여 줄 수 있다 |
| 마이크가 안 된다 | 휴대폰·태블릿은 HTTPS 주소(터널)로 열어야 마이크가 된다. 안 되면 PC에서 시연한다 |

## 4. 꼭 지킬 것

- **실제 아이의 목소리·그림을 넣지 않는다.** 지금 쓰는 AI는 무료 등급이라 입력이 학습에 쓰일 수 있다. 아이와 시연할 때는 샘플 그림을 쓰고, 녹음은 어른이 한다. 실제 아이 테스트 전에는 유료 키로 바꾸고 보호자 동의를 받아야 한다.
- **터널은 시연하는 동안만 켠다.** 켜져 있는 동안은 주소를 아는 누구나 개발 서버에 들어올 수 있다. 끝나면 터널 창을 닫는다.
- 저장된 그림책은 시연 후 지운다. 로컬은 `data/books` 폴더, 버셀은 Storage → Blob 저장소의 `books/` 폴더.
